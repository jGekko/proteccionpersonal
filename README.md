# Detección de Elementos de Protección Personal

Esta aplicación web basada en Streamlit permite analizar una imagen y detectar si una persona está utilizando los elementos de protección personal (EPP) adecuados, como casco, chaleco y gafas. Fue desarrollada con fines educativos y de concientización sobre la seguridad en entornos laborales.

Mediante el uso de modelos de visión por computadora, la app analiza la presencia de los elementos obligatorios y genera un resultado visual e informativo sobre el cumplimiento de las normas.

> Enfoque en seguridad laboral mediante análisis visual automatizado.

## Características

- Subida de imágenes local o por camara
- Detección de casco, botas y chaleco
- Clasificación visual de cumplimiento
- Interfaz simple y accesible vía web
